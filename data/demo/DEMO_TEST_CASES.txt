PREDICTIVE MAINTENANCE DASHBOARD - DEMO TEST CASES
==============================================================================

Model artifact      : 71406426
Decision threshold  : 0.70
Risk bands          : Low < 35%  |  Medium 35% to <70%  |  High >= 70%
Dataset             : AI4I 2020 predictive-maintenance reference data

HOW TO USE
------------------------------------------------------------------------------
1. Start the dashboard and open Run prediction -> CSV batch.
2. Upload data/demo/demo_test_cases.csv.
3. Keep "This CSV contains reference or simulated data" checked.
4. Click Analyze batch and select each DEMO-* row to inspect the result.
5. Compare the model probability and risk band with the actual label below.

The CSV contains only the six model inputs and a Machine ID. Actual labels
and expected risk bands are kept in this text file so the upload remains
compatible with the application.

WHAT EACH GROUP DEMONSTRATES
------------------------------------------------------------------------------
Normal cases
  DEMO-NORMAL-01/02: clean low-risk readings. Both score below 1% and
  should appear in the Low band. They provide a baseline for comparison.

Tool-wear failure (TWF)
  DEMO-TWF-01/02: tool wear above 200 minutes. TWF is driven by accumulated
  tool use; the model scores both cases above 95% and classifies them High.

Heat-dissipation failure (HDF)
  DEMO-HDF-01/02: low process-to-air temperature difference and high torque.
  HDF occurs when heat cannot be dissipated; both cases score above 99%.

Power failure (PWF)
  DEMO-PWF-01/02: high torque at moderate speed, i.e. a high mechanical
  power demand. Both cases score above 99% and are High risk.

Overstrain failure (OSF)
  DEMO-OSF-01/02: high torque combined with high tool wear. Both cases
  score above 99% and are High risk.

Watch-band cases
  DEMO-WATCH-01/02: actual no-failure readings that fall in the Medium band
  (35% to <70%). They demonstrate why the dashboard recommends condition
  checks rather than automatically replacing a part.

False alarms
  DEMO-FALSE-01/02: actual no-failure readings that score above 70%. They
  demonstrate the false-positive cost of the selected threshold and are
  useful for discussing precision versus recall.

Missed failures
  DEMO-MISS-01/02: actual TWF failures that score below 70%. They show the
  residual false-negative risk; the model is not a guarantee of detection.

Random-failure indicator
  DEMO-RNF-01: the dataset marks RNF=1 but Machine failure=0. Random
  failures are not explained by the six inputs, so this case is an honest
  reminder that not every failure mode is learnable from this feature set.

NOTES
------------------------------------------------------------------------------
- Probabilities are scores from the saved model, not calibrated chances.
- The app predicts failure/no-failure, not the failure mode; modes above
  are the dataset labels for interpretation.
- Reference/simulated rows are excluded from machine alerts by design.
- Results are deterministic for model artifact 71406426.
- Model performance is validation evidence; see Model performance in the app.
